# Game Gameplay Videos Directory

Place your custom gameplay recording files here to replace the sample video streams.

### Recommended Files:
1. `void-breach.mp4` (or `orbital-breach.mp4`) — Gameplay recording for **Void Breach** (FPS Tactical CQC).
2. `one-wrong-step.mp4` — Gameplay recording for **One Wrong Step** (3D Puzzle Platformer).
3. `ashen-veil.mp4` — Gameplay recording for **Ashen Veil** (Dark Fantasy Action RPG).

### Format:
- **Format:** MP4 (H.264 / AAC) or WebM
- **Resolution:** 1080p or 4K, 60 FPS
- **File size:** 10MB - 50MB (optimized for web streaming)

Whenever you add your files, update `GAME_VIDEO_DATA` in `src/components/DiscographyProjects.jsx`:
```js
videoSrc: '/videos/void-breach.mp4',
```
